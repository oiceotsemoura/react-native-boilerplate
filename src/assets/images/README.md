# Image Assets

This folder should contain the required image assets for the Expo app:

## Required Images

1. **icon.png** (1024x1024)
   - App icon shown on the home screen

2. **splash.png** (1284x2778 or larger)
   - Splash screen shown when app launches
   - Should have a transparent or white background

3. **adaptive-icon.png** (1024x1024)
   - Android adaptive icon (foreground layer)
   - Center 512x512 should contain the main icon

4. **favicon.png** (48x48 or larger)
   - Web favicon

## Generating Assets

You can:
1. Add your own images following the specifications above
2. Use Expo's asset generation: https://docs.expo.dev/develop/user-interface/app-icons/
3. Use tools like: https://www.appicon.co/

## Temporary Placeholders

For development, you can use simple colored squares as placeholders.
The app will work without these during development in Expo Go.
